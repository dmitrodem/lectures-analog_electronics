# Аналоговая электроника

В репозитории собраны готовые материалы курса «Аналоговая электроника» для
студентов: презентации лекций и рекомендуемая литература.

## Лекции

1. [Зонная структура полупроводников и диод](<lectures/01_зонная_структура_полупроводников_и_диод/presentation.pdf>)
2. [Принцип усиления и транзисторы](<lectures/02_принцип_усиления_и_транзисторы/presentation.pdf>)
3. [Эквивалентные схемы и частотные характеристики](<lectures/03_эквивалентные_схемы_и_частотные_характеристики/presentation.pdf>)

Презентации следующих лекций будут размещаться в каталогах вида
`lectures/NN_название/presentation.pdf`.

## Литература

- [A. S. Sedra, K. C. Smith — Microelectronic Circuits, 6th Edition](<books/Microelectronic Circuits by Sedra and Smith 6th Edition.pdf>)
- [В. Т. Ларин — Аналоговая электроника](<books/Аналоговая электроника (Ларин).pdf>)
- [Е. И. Манаев — Основы радиоэлектроники](<books/Основы радиоэлектроники (Манаев).djvu>)

презентаций и промежуточные результаты сборки здесь не размещаются.

Права на книги принадлежат их авторам и издателям. Материалы предоставлены для
использования в рамках учебного курса.
